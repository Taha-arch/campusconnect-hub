# CampusConnect Hub

Build the frontend using React 19, Vite, JavaScript/JSX, React Router,

and plain CSS. Keep an existing responsive layout and use the CampusConnect

design tokens. Primary teal: #1E847F. Secondary sand: #ECC19C.

Third/neutral: #000000. White: #FFFFFF. Background: #FAF4EC.

Use Poppins for headings and Inter for body text. Preserve the existing

/routes and component structure.

This project was built with [Lovable](https://lovable.dev).
